# LocalFind · 本地寻

用一句话查找 Mac 里的文档、图片和代码。下载安装后在本机离线使用。

## 下载 Mac 版

**[下载离线安装包（约 575 MB）](https://github.com/KYG520/LocalFind/releases/download/v1.01/LocalFind-1.0.1-mac-arm64-offline.zip)**

[版本说明与全部下载文件](https://github.com/KYG520/LocalFind/releases)

适用于 Apple Silicon（M1 及更新芯片），macOS 14 及以上；不支持 Intel Mac 和 Windows。模型已包含，无需另行下载。

## 第一次使用

1. 下载 ZIP 并解压，将 LocalFind.app 放入“应用程序”。
2. 打开应用，添加想搜索的文档与图片目录，或代码目录。
3. 点击“建立索引”，等待完成。首次处理需要时间。
4. 输入描述搜索，例如“合同里的付款条款”或“重试失败请求的方法”。

文件新增或修改后，需要再次点击“建立索引”。当前不支持音频和视频，搜索结果可能不准确，请核对原文件。

## 本地处理

应用运行时不连接网络，只读取你选择的本地目录；索引保存在本机。此下载包不包含使用者的文档或索引。
